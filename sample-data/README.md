# Sample data (synthetic)

DEMO DATA — NOT REAL STUDENT INFORMATION. All identifiers use the deliberately unreal
`DEMO-APAAR-######` format.

| File | Use |
|---|---|
| `student-upload-template.csv` | The canonical header row plus one example row (same as *CSV template* in the app) |
| `malformed-wrong-headers.csv` | Upload it to see a whole-file rejection (`MISSING_COLUMNS`) |

The main demo file is generated by the app (**Uploads → Demo sample file**, or
`GET /api/v1/demo/sample-upload.csv`) so that its academic year and identifiers always match
the seeded database. It contains 171 rows with 11 planted problems — see
[`docs/testing-and-evaluation.md`](../docs/testing-and-evaluation.md).
